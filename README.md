
제목: FitMate
기간: 2024. 10. 1 ~ 2024. 11. 11
인원: 4명
개발 내용: 운동 성향 및 위치 기반 사용자 매칭 서비스
담당 기능:
- 실시간 채팅: 웹소켓을 활용한 1:1 및 다대다 채팅, 반응형 페이지로 제작
- 개인 운동 일지: Calendar API를 활용한 개인/크루 일정 조회 및 개인 일지 작성 기능 구현
- 헬스 MBTI 검사지, 결과지: 질문 및 결과 도출, 중첩 객체를 활용한 선택 값 추적 및 선형 탐색 알고리즘의 응용으로 최대 점수의 운동 유형 도출 기능 구현
- 알림: setInterval을 활용한 알림 읽음 여부 확인 및 탭 필터링, url로 이동이 가능한 알림 구현

트러블 슈팅: 
1) 실시간 채팅 웹소켓을 활용하여 개선
문제: 기존 setInterval로 DB 조회를 하던 방식에서 실시간 채팅 기능 구현에 한계가 있었음.
해결: 웹소켓을 활용하여 실시간 1:1 및 다대다 채팅 기능을 구현. 세션 정보를 static 영역에 저장하여 세션 관리 문제를 해결하고, 웹소켓 접속 사용자들에게만 알림을 전송하도록 개선.

2) 헬스 MBTI 문항 취소 후 재 선택 문제
문제: 헬스 MBTI 문항 선택 시, 이전 선택 값을 식별할 수 없어서 결과 계산에 문제가 발생.
해결: 중첩 객체를 사용하여 각 페이지 및 질문 별로 선택 값을 저장하고, 이전 선택값을 차감하여 새로운 값을 합산할 수 있도록 구현. 선형 탐색 알고리즘을 활용해 최대 점수를 계산하여 결과를 도출.
